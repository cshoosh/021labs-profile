# 021Labs Profile

The public profile website for 021Labs, built as a lightweight static site and hosted on Firebase Hosting at [021labs-online.web.app](https://021labs-online.web.app).

## Local preview

Serve the `public/` directory with any static file server.

## Deploy to Firebase Hosting

Install the Firebase CLI, authenticate with an account that has access to the Firebase project, then run:

```sh
firebase deploy --only hosting
```

The site configuration uses the `021labs-online` Hosting site in the `abc-friends-public` Firebase project.
